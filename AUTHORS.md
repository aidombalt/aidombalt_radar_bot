# Сведения о создании проекта и распределении ролей

Проект: «Радар упоминаний ГК „Балтийский Дом“».
Исходная версия приложения: 2026.11.03-max7.
Поставка для передачи: 2026.11.05-handover.1 от 05.11.2026.

Инициатор и создатель исходного проекта: Кузнецов Лев Андреевич.
Должность: PR-менеджер, специалист организационно-аналитического Департамента группы управляющих компаний "Балтийский Дом".

Сведения о роли автора приведены по его заявлению. Проект создан им для рабочих задач мониторинга упоминаний ЖК с применением инструментов генеративного ИИ. Это описание происхождения проекта, а не независимая экспертиза авторства каждого фрагмента кода.

Заявленный вклад: инициатива создания бота, формирование требований к мониторингу и анализу, разработка и настройка исходного решения с помощью ИИ, подготовка предметных справочников и проверка результата в работе. Перед подписанием уточнить перечень по фактическому личному вкладу.

| Область | Предлагаемый ответственный |
|---|---|
| Методика анализа, критерии риска, состав объектов и приёмка результата | ОАД; персональный ответственный указан в акте |
| Первоначальная разработка и рабочий прототип | Указанный выше создатель проекта |
| Сервер, сеть, учётные записи, резервное копирование и доступность | IT; персональный ответственный указан в акте |
| Последующие изменения программного кода | Фактические исполнители с фиксацией в корпоративном репозитории |
| Изменение правил приоритетов и отправки уведомлений | По согласованию с ответственным за методику от ОАД |

При подготовке этой поставки с помощью ChatGPT изменены файлы развёртывания, добавлены внешнее размещение секретов, проверка конфигурации, тесты этих изменений и документы передачи. Перечень — `CHANGELOG_HANDOVER.md`. Правила анализа и исходные тесты не изменялись.
