# 📡 Радар упоминаний ГК «Балтийский Дом»

Сборка 2026.11.03-max7. Подключение Max и порядок обновления: [README_MAX.md](README_MAX.md). Что нового — [ниже](#что-нового-в-20261103-max7).

Радар круглосуточно читает ВКонтакте, включая **комментарии у губернаторов**, а также Telegram, СМИ Петербурга и Ленобласти и Google News. Он находит публикации о наших УК и ЖК **и о соседях по кварталу**, а ИИ оценивает, насколько каждая из них опасна. Срочное приходит в Telegram, Max и на почту за минуты. Отчёты уходят в Excel и Word по расписанию, в том числе когда упоминаний нет.

```
 Сервер в РФ (24/7)                                   Google Colab Pro (GPU)
 ┌─────────────────────────────────────────┐          ┌──────────────────────────────────┐
 │ сбор: ВК API (стены+комменты), СМИ RSS, │  HTTPS   │ большой мозг: Qwen3.8-27B / Gemma 4│
 │ госсайты → матчер → очередь ИИ          │ ◄──────  │ (vLLM/Ollama) + агент с памятью   │
 │ малый мозг (Gemma 4 E4B, CPU) — страховка│  только  │ сбор: Telegram, Google News       │
 │ риск → алерты (Telegram/почта) → отчёты │ исходящие│ ретранслятор алертов в Telegram   │
 │ GUI :8080 · бот · планировщик · сторож  │  из Colab│ сторож сервера                    │
 └─────────────────────────────────────────┘          └──────────────────────────────────┘
```

## Установка (10 минут)

```bash
sudo apt update && sudo apt install -y python3-venv git curl
sudo useradd -m radar && sudo mkdir -p /opt/radar && sudo chown radar /opt/radar
# скопируйте папку проекта в /opt/radar, затем:
cd /opt/radar
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
cp .env.example .env && nano .env          # заполните токены, пароль GUI и BRIDGE_TOKEN
# страховочная модель на сервере (≈3 ГБ):
curl -fsSL https://ollama.com/install.sh | sh
ollama pull hf.co/google/gemma-4-E4B-it-qat-q4_0-gguf
# проверка: один цикл сбора
.venv/bin/python run.py --once hot
# автозапуск
sudo cp deploy/radar.service /etc/systemd/system/ && sudo systemctl enable --now radar
(crontab -l; echo "*/5 * * * * /opt/radar/deploy/radar-watchdog.sh") | sudo crontab -
```

Вариант «в один клик» через Docker: `cd deploy && docker compose up -d --build`.

### Пилот на Windows-ноутбуке
1. Поставьте [Python 3.12](https://www.python.org/downloads/) (галочка «Add to PATH») и [Ollama для Windows](https://ollama.com/download).
2. `ollama pull hf.co/google/gemma-4-E4B-it-qat-q4_0-gguf`: модель встанет на видеокарту (RTX 3060, 6 ГБ). **Драйвер NVIDIA должен быть свежим.** Со старым драйвером (2023 года) Ollama считает через Vulkan, и получается в 5–10 раз медленнее. В `%LOCALAPPDATA%\Ollama\server.log` должно стоять `library=CUDA`.
3. Скопируйте `.env.example` в `.env` и заполните.
4. Проверка сети: `start_radar.bat --netcheck`. Команда проверит ключи ВК и Telegram, почту, госсайты, t.me и Google News. Секреты в вывод не попадают.
5. Проверка мозга: `start_radar.bat --brain-test` прогонит 10 эталонных постов через локальную модель. Норма до минуты на пост. Если выходит дольше, модель не успевает: проверьте, что ноутбук на зарядке и Ollama работает на NVIDIA.
6. Двойной клик по `start_radar.bat`. Проверка одного цикла: `start_radar.bat --once hot`. **Выключить или перезапустить** — кнопка ⏻ справа в шапке веб-интерфейса (окно консоли закроется само). Ctrl+C в консоли тоже завершает Радар штатно; на вопрос Windows «Terminate batch job (Y/N)?» ответьте Y.
7. Чтобы Радар работал круглосуточно: Электропитание → «Сон: никогда», «При закрытии крышки: ничего не делать». В Планировщике заданий: «При входе в систему» → `start_radar.bat`.

**Мост для Colab с ноутбука за роутером:** нужен адрес, доступный из интернета. Свой домен для этого не нужен. Варианты:
- **Без домена:** строка `TUNNEL=cloudflared` в `.env`. Радар сам поднимет туннель Cloudflare и пришлёт в бот адрес `https://….trycloudflare.com` для секрета `RADAR_URL` в Colab. Если туннель перезапустится и адрес сменится, бот пришлёт новый.
- **Надёжно (рекомендуется):** VPS в РФ с Ubuntu, 1 ядро и 1 ГБ памяти хватит. В `.env` пропишите `TUNNEL=ssh` и `TUNNEL_HOST=IP`, затем запустите Радар. Он создаст ключ и файл `data\vps_setup_ready.sh`. Откройте файл в Блокноте, скопируйте целиком и вставьте в консоль VPS от root, это делается один раз. Адрес моста постоянный: `https://IP-с-дефисами.sslip.io`. Проверка: `start_radar.bat --netcheck`.
- **Проброс порта 443** на роутере офиса плюс бесплатное имя (DuckDNS / sslip.io).

**Релей для Telegram и Google News.** Если `--netcheck` показывает ❌ у Telegram и Google News, а у Cloudflare ✅, поставьте бесплатный релей на Cloudflare Workers. Инструкция на 10 минут лежит в начале `deploy/cloudflare_worker.js`. После этого в `.env` появится строка `RELAY_URL=…`. Бот, t.me и Google News пойдут через релей, а ВК и госсайты по-прежнему напрямую.

Через любой туннель снаружи открыт мост `/api/brain/*`, `/health` и точный путь `/api/max/webhook` (с отдельным секретом), веб-интерфейс пускает только из локальной сети (`monitor/netguard.py`).

**Сеть:** Colab должен достучаться до сервера по HTTPS. Пример в `deploy/Caddyfile`: мост для Colab открыт в интернет и защищён токеном, веб-интерфейс доступен только из офиса или через VPN.

## Настройка Telegram-бота (5 минут, один раз)

1. В Telegram откройте **@BotFather** → `/newbot` → имя (например, «Радар Балтийский Дом») → адрес, оканчивающийся на `bot` (например, `baltdom_radar_bot`). BotFather пришлёт **токен** вида `1234567890:AA…`.
2. Впишите токен в `.env`: `TG_BOT_TOKEN=1234567890:AA…` (токен никому не пересылайте).
3. Запустите Радар (`start_radar.bat`). Откройте своего бота в Telegram → «Старт». Бот ответит **вашим id**.
4. Впишите id в `.env`: `TG_ADMINS=ваш_id` (несколько — через запятую) и перезапустите Радар. Теперь у бота есть меню команд.
5. Отправьте боту `/test` — должен прийти тестовый алерт. Коллег добавляйте командой `/adduser id viewer|manager|admin`.
6. **Алерты в рабочую группу PR:** добавьте бота в группу, напишите там `/start` — бот покажет id группы (с минусом). Впишите его в `TG_ADMINS` через запятую.

Если бот молчит: откройте на ноутбуке без VPN https://api.telegram.org. Не открывается — Telegram из вашей сети режется, нужен прокси (GUI → Настройки → «Прокси для Telegram Bot API»). Пока его нет, алерты дублируются на почту.

## Первый запуск

1. Откройте `http://сервер:8080` и введите пароль из `GUI_PASSWORD`.
2. Настройте бота по разделу выше и отправьте ему `/test`.
3. Откройте **Настройки** и укажите почту для отчётов. Кнопками «Тест Telegram» и «Тест почты» проверьте доставку.
4. Colab: откройте `colab/brain_worker.ipynb`, в 🔑 «Секретах» добавьте `RADAR_URL` и `RADAR_TOKEN` (= `BRIDGE_TOKEN`), выберите GPU **L4** или **A100** и нажмите «Выполнить всё». В GUI на вкладке «Мозг» должно появиться «🟢 онлайн». **Colab не круглосуточный**: 100 CU в Pro — это ≈ 13 ч на A100 или ≈ 58 ч на L4 в месяц. Круглосуточно работает локальная модель, Colab включаем как усилитель. `MAX_HOURS` в ноутбуке сам выключит сессию. Пока Colab офлайн, Telegram-каналы опрашивает сервер, если t.me из вашей сети открывается; статус виден в `/status`.
5. **Источники и люди добавляются по ссылке.** На вкладке **Источники** вставьте ссылку на Telegram-канал, группу ВК или сайт СМИ и нажмите «Найти». Радар покажет название, число подписчиков и последний пост, сам определит тип и регион, предупредит о дубле. Останется нажать «Добавить в мониторинг», первый опрос пройдёт сразу. Людей (страница ВК, @ник в Telegram) добавляйте так же на вкладке **Наблюдение**: их посты и комментарии в любом паблике сразу уходят на разбор ИИ. Второй аккаунт того же человека добавляется в его карточку.
6. То же в боте: пришлите ему просто ссылку (или `/add ссылка`) и выберите кнопку «🔥 каждые 5 мин», «⏱ каждые 15 мин» или «👤 Поставить на контроль». Нужна роль manager или admin.
7. **Рекомендованный набор.** На вкладке **Источники** раскройте «📋 Рекомендованный набор» (≈80 источников: СК и «приёмная Бастрыкина», надзор по ЖКХ, МЧС, паблики Мурино/Кудрово/Сертолово/Солнечного города, Mash, наши группы УК). Обязательные (★) уже отмечены, осталось нажать «Проверить и добавить». Радар откроет каждую ссылку и добавит только живые; рядом со строкой будет видно, что пропущено и почему. Следите за строкой «Нагрузка на ключ ВК»: у ВК суточный лимит ≈5000 вызовов `wall.get`.
8. Внизу вкладки **Источники** одобрите паблики, найденные автопоиском.

### Чего Радар не видит и как это закрыть

- **Закрытые чаты домов и чаты при каналах** (`chat9online`, `tmurino_chat`, «старые чаты» ЖК). Жалобы начинаются там, но читать их может только участник. Выход: сотрудник УК в чате пересылает тревожные сообщения боту.
- **Max как источник публикаций.** Эта сборка добавляет доставку и управление в Max. Сбор чужих каналов Max в мониторинг не входит; источники продолжают опрашиваться через ВК, Telegram, RSS и сайты.
- **Отзывы 2ГИС и Яндекс Карт.** Рейтинги УК уже на дне (1,3–1,9★), поэтому важен рост числа отзывов за неделю. Пока это ручная проверка раз в неделю.
- **Суды, КАД, Федресурс, реестр лицензий ГИС ЖКХ.** История с перерасчётом в Солнечном городе полгода зрела в арбитраже (А56-122433/2023), прежде чем попала в СМИ. Автоматизировать можно через платный агрегатор (Checko, ofdata) по ИНН наших ООО.

## Что делать при алерте

🔴 **P1: реагировать в течение 30 минут.** 🟠 **P2: в течение 2 часов.** 🟡 P3 попадает в отчёт.

Сначала нажмите **«✅ Беру в работу»**, иначе через 15 минут алерт уйдёт руководителям. Проверьте факт на объекте. Кнопка «✍️ Черновик ответа» даст готовый официальный ответ от лица УК, поправьте его и опубликуйте. Если сработка ошибочная, нажмите «❌ Ложное»: Радар запомнит это и будет точнее. Карточка меняется на месте и сразу у всех получателей. «В работе» дописывает, кто взял. «Решено» и «Ложное» сворачивают карточку в две строки, а кнопка «↩️ Вернуть» отменяет ошибочное нажатие. Через 30 минут («Ложное», «Снято») или 2 часа («Решено») карточка исчезает из чатов Telegram и Max вместе с напоминаниями и ответами «Черновик»/«Динамика»; сама публикация остаётся в Радаре и в отчётах, вернуть её в чат — `/item N` или «↩️ Вернуть» в карточке в веб-интерфейсе. Перепосты той же истории после «Ложное» или «Решено» больше не приходят.

**Нерабочее время (вечер, ночь, выходные).** P1 приходит всегда. P2 будит, только если есть хотя бы одно из:
- надзор или прокуратура (ГЖИ, СК, смена УК);
- публикация СМИ или власти;
- жалоба адресована губернатору или надзору;
- массовая авария (свет, вода, тепло, затопление, пожар);
- призыв к соседям.

Остальные P2 приходят к началу рабочего дня с пометкой «🌙 отложено». Если к утру вопрос закрыли, алерт не приходит вовсе. Происшествия, которыми занимаются полиция и охрана («подозрительный мужчина у лифта»), не поднимаются выше P3 и попадают только в отчёт. Исключение — если в тексте есть претензия к УК, охране, камерам, домофону. Рабочее время и переключатель — в Настройках → «Кому что приходит».

**Кому что приходит.** Настройки → таблица «получатели × события»: P1, P2, эскалации, утренний, дневные и недельный отчёты, служебные сообщения. Умолчания:
- менеджерам в Telegram — всё;
- руководству на почту — P1, эскалации, утренний и недельный отчёты, без служебных.

Один человек занимает одну строку. В каждой ячейке две галочки: ✈️ — в Telegram, ✉️ — на почту. Почта, указанная у пользователя бота, показывается в его строке. Отдельной строкой идут адреса, которые есть только в «почте для отчётов» (обычно руководство). Строка «из .env (TG_ADMINS)» — администратор, прописанный в `.env`, но не заведённый в пользователях. Добавьте его id в пользователи с именем и почтой, и строка станет обычной.

**Ссылки на статьи.** news.google.com в РФ закрыт, поэтому в алертах и отчётах Радар даёт ссылку на саму статью. Оригинал он ищет по порядку:
1. Разбирает идентификатор Google.
2. Ищет ту же статью в базе.
3. Спрашивает у Google через релей (v5).

Если оригинал пока не найден, ссылка ведёт на поиск Яндекса по заголовку и сайту (подпись «найти статью (поиск)»). Фоновая задача раз в 10 минут дорешивает такие ссылки, дочитывает полный текст статьи и обновляет карточку. «📈 Динамика» у статей СМИ показывает распространение: кто перепечатал или пересказал и сколько вышло по теме после. Счётчиков просмотров у сайтов нет.

**Волна по одной теме.** Если по той же теме в том же районе выходит ещё P2, пока первый инцидент открыт (как 24.09: отключение света в Мурино), второй алерт не приходит. Вместо этого в карточке открытого инцидента обновляется строка «📰 По теме после этого: N публ.». P1 приходит всегда. «📈 Динамика» перед ответом берёт свежие цифры поста. У Telegram это просмотры: реакции и комментарии веб-версия t.me не отдаёт.

**Как читать отчёт.** Первая строка — **состояние сейчас**, а не только итоги периода:
- 🟢 спокойно;
- 🟡 есть что держать на контроле;
- 🟠 открыт инцидент: кто взял и когда;
- 🔴 P1 без ответа.

Дальше: «После последнего инцидента (что, где, статус) новых упоминаний наших объектов не было / появилось N» и отметка «случилось в нерабочее время; взят в работу через …». Инцидент, открытый вечером, попадает и в утренний отчёт, пока его не закроют. Текст «Коротко» пишет модель (Colab или локальная) по фактам. Если модели нет или она сорвалась в тревожные формулировки при спокойной обстановке, текст собирается по шаблону. **Excel — это данные** (инциденты, сюжеты, все упоминания, лента по часам, динамика постов, проблемные площадки). **Word — записка для чтения** на 1–2 страницы.

**Что будит людей.** P1/P2 приходят, только если в тексте, в посте или в ветке есть наша УК, ЖК или адрес из списка. Улица без номера дома — это район, а не наш дом: P3, в отчёт (на проспекте Обуховской Обороны наш один дом из сотен). Исключение — улицы, где почти все дома наши: их можно перечислить в Настройках («Улицы, где почти все дома наши»), там улица без номера даёт P2. Просто район (Мурино) или соседняя УК дают P3, это в отчёт. Если ничего нашего нет, это P4: такое остаётся в ленте и никому не приходит.

Названия ЖК мало, нужна **наша тема**. Если ЖК или адрес служит только ориентиром (потерялся кот у ЖК, потеряли ключи у дома, «сдам/продам»), это P4, даже если модель насочиняла «безопасность жильцов». Если нет ни жалобы, ни угрозы, ни надзора (анонс, нейтральная новость), то не выше P3, в отчёт. Будят только проблемы, за которые спросят с УК или застройщика. Проверить конкретный текст: `/replay текст` в боте.

**P1 — это два ключа.** Нужен негатив про наш объект и что-то одно из списка: адресовано губернатору или надзору, публикация СМИ, призыв к коллективным действиям, угроза или затяжная авария («четверо суток нет воды»), быстрый рост реакций, волна жалоб. Охват автора (инфлюенсер, депутат, человек на контроле) сам по себе даёт P2, то есть «ответить в течение 2 часов». Хроника («подвал затоплен уже несколько месяцев») острой не считается. Почему приоритет такой, видно в карточке в GUI (строка «риск»).

**Одна проблема — одно сообщение.** Ещё публикация про то же место и ту же тему, пока инцидент открыт, дописывается в его карточку («📰 По теме после этого»). Отдельное сообщение придёт, если история поднялась на новый уровень: дошла до губернатора или СМИ, или P2 стал P1.

**Найдено с опозданием.** Бывает, что публикация вышла больше 12 часов назад, а Радар увидел её только сейчас: подключили новый источник или человека, или был перерыв в работе. Такие находки приходят **одной сводкой** «📥 Найдено с опозданием» с кнопками, открывающими полные карточки. Эскалаций по ним нет. История старше 3 дней (`schedule.max_age_days`) уходит в архив без анализа. Это правило действует и для людей на контроле. Порог сводки: `alerts.late_hours`.

**Письма.** P1 приходит письмом один раз. Эскалация уходит руководству письмом только первая, повторы идут в Telegram. Если у сотрудника Telegram не принимает сообщения (не нажал «Старт» у бота), копия уходит на **его** почту, а администратору приходит одно сообщение об этом.

📥 Увидели жалобу в закрытом домовом чате? **Перешлите сообщение боту**, и оно уйдёт в анализ, как любое другое.

### Чужой дом в нашем ЖК (с версии 2026.10.09)

В ЖК, где мы обслуживаем только часть корпусов, Радар больше не считает название ЖК доказательством «нашего», если в тексте назван конкретный корпус, которого нет в нашем списке. Так, «дом №13к1 на Европейском (ЖК «Прогресс»)» — это УК «Сервис+», а не мы, поэтому публикация уходит в отчёт без алерта. Наш корпус в тексте (13к2, 13к4…), наша УК или фразы вроде «во всём ЖК» и «а у нас то же самое» оставляют публикацию срочной. Номер дома теперь распознаётся и перед улицей («жители дома №13к2 на Европейском»), поэтому такие жалобы на наши дома тоже приходят.

- **Полнота справочника.** В GUI → «Объекты» в блоке «Полнота списка наших домов по ЖК» у каждого ЖК есть галочка «Список полный». Если она стоит, неизвестный корпус этого ЖК точно не наш и уходит в отчёт. Если не стоит, придёт P2 «дом не из справочника — проверить» с кнопками «🏠 Наш дом» и «🚫 Не наш». Ночью такая карточка ждёт утра. Сейчас галочки стоят у всех ЖК, кроме «Москвы»: там апартаменты БСК записаны без адресов.
- **Кнопки выучивают дом.** «🏠 Наш дом» и «🚫 Не наш» (на любой карточке, где разобран чужой дом) записывают адрес в `config/entities.learned.yaml`. Обновление архива этот файл не перезаписывает. Записи видны в GUI → «Объекты», там же их можно удалить. Раз в неделю отчёт показывает их на пересмотр.
- **Та же история.** Перепосты и пересказы публикации, которую вы отметили «❌ Ложное» или которая про чужой корпус, не будят людей: они получают P3 и не приходят отдельной карточкой. Для этого нужна общая ссылка, сумма, имя или почти дословная копия. В карточке исходной публикации появляется строка «📎 ещё N копий». Перепост, пришедший раньше исходной публикации, понижается в течение минуты. «↩️ Вернуть» отменяет это для всей истории.
- **Что не пришло** — `/skipped 24` в боте: список с причинами и кнопкой «✅ Наше», которая вернёт публикацию алертом. В отчёте Excel то же на листе «Не присланы». Первую неделю после обновления каждое утро приходит одна сводка «🧩 Склейки и чужие дома за сутки», чтобы новую логику было легко проверить.
- **Эскалации без дублей.** Если P1 не взяли в работу, повторная карточка в тот же чат больше не приходит. Существующая карточка обновляется («⏰ не взято в работу · эскалация 2/4»), и под ней появляется короткое напоминание. В чате всегда одна карточка и не больше одного напоминания. «Беру», «Решено» и «Ложное» убирают напоминание.
- **Проверка склеек на своей базе:** `python run.py --case-audit 30` выгружает в `data/reports/case_audit_30d.xlsx` все пары публикаций, которые Радар считает «той же историей».

## Что нового в 2026.11.03-max7

Разбор случая 03.11: комментарий «Водоканал, ждём срочно с проверкой в ЖК Солнечный город» пришёл как 🟠 P2 «ЖК управляется УК Цивилизация», хотя дом не назван, а в ЖК с нами соседствуют другие УК. Пост, под которым он написан, оператор накануне отметил «❌ Ложное».

- **Общий ЖК без нашего дома — не наш объект.** В справочнике у ЖК появилась отметка «есть дома других УК» (`shared: true`; GUI → Объекты, галочка рядом со «Список полный»). Для «Солнечного Города» она уже стоит. Название такого ЖК без нашего дома и без нашей УК даёт P3 (в отчёт), в карточке не пишется «УК: …», модели подсказка говорит, что дом может быть чужим. Срочно остаётся, если назван наш дом (Буденного 19к1), наша УК («Цивилизация») или «во всём ЖК / все корпуса».
- **«Ложное» действует на комментарии.** Комментарий под постом, отмеченным «❌ Ложное» (или под его копией), наследует вердикт: P3 без карточки, виден в `/skipped`. Не наследует, если комментатор назвал наш дом или нашу УК. Под постом с «🟢 Решено» комментарий придёт, если проблема вернулась («опять», «снова»), появилась претензия к УК, власть или СМИ. Если отметить пост после того, как комментарий уже пришёл, его карточка свернётся сама в течение минуты. Модель тоже видит в памяти строку «ВЕТКА: исходный пост отмечен «Ложное»».
- Разметка упоминаний ВК (`[club91135910|Водоканал Санкт-Петербурга]`) в карточках и анализе превращается в обычный текст.

## Что нового в 2026.10.23-max6

Разбор случая 23.10 16:30: пост СК «жители дома на проспекте Обуховской Обороны… возбуждено уголовное дело» пришёл как 🟠 P2 «касается нашего ЖК Дом-Мегалит на Неве». Номера дома в посте нет; наш на этом проспекте один дом (195) из сотен.

- **Улица без номера дома — не наш объект.** Потолок такой публикации теперь P3 (в отчёт, раздел «фон по районам»). P2 по улице — только для улиц, где почти все дома наши, если вы их перечислите (Настройки → «Улицы, где почти все дома наши» или `risk.street_dense`). С номером нашего дома («Обуховской Обороны, 195») — срочно, как раньше.
- **Подсказка для ИИ больше не подставляет ЖК к улице.** Было «улица: Обуховской Обороны → ЖК Дом-Мегалит на Неве» — модель принимала это за доказательство. Теперь: «номер дома НЕ назван; наших домов на ней: 195, остальные чужие → не наш объект». Это же правило добавлено в инструкцию модели и в самотест `--brain-test`.
- **ИИ не может «назначить» публикацию нашей.** Если модель отвечает «наш объект», а в тексте (или в посте, к которому комментарий) нет нашей УК, ЖК или адреса, Радар исправляет её вывод до расчёта риска: «связь — район/сосед», приоритет не выше P3, «Чем опасно» заменяется на «в тексте названа только улица…», черновик ответа от УК убирается. Исключения: человек на контроле, пересланное оператором, комментарии в наших группах, «✅ Наше» от оператора.
- Уже пришедшая карточка этого поста свернётся сама в течение минуты после обновления (сверщик) и через 30 минут исчезнет из чата.

## Что нового в 2026.10.23-max5

Разбор случая 21–23.10: пост «подростки забрасывают яйцами дверь пенсионеров, ЖК Виктория, Авиаторов Балтики 9к2» четыре раза пришёл как 🟠 P2 «ответить от лица УК», хотя УК в истории нет, и возвращался после «❌ Ложное».

- **Чья это проблема.** Хулиганство, вандализм, травля людей, конфликт соседей без претензии к УК — это зона полиции и самих жильцов: P3, в отчёт, без алерта. Срочным такой пост остаётся, если в нём есть претензия к УК или к общему имуществу (охрана, камеры, домофон, лифт не работает, дверь подъезда не закрывается), жилнадзор или угроза в доме. Публикации СМИ и власти не понижаются. ИИ теперь сначала отвечает, чья это зона ответственности (УК, застройщик, полиция, соседи, город), и только потом ставит приоритет; его вывод понижает приоритет, только если в тексте нет претензии к УК и темы ЖКХ.
- **«Судя по записи» больше не «суд».** Тема «суд/прокуратура/надзор» ловилась по началу слова «суд…» и снимала потолок «не про работу УК». Теперь — только формы слов «суд», «судебный», «судья», «судиться».
- **Решение оператора держится за историю.** «❌ Ложное» гасит перепосты и пересказы этой публикации 30 дней (`story.verdict_days`), «🟢 Решено» — 72 часа (`story.resolved_hours`), даже если в них назван наш адрес, но только почти дословные копии (`story.verdict_copy_min`). Копия «решённой» истории придёт снова, если дошла до губернатора, надзора, СМИ, в ней появился призыв или слова «опять», «снова» (проблема повторилась); любая копия придёт, если в ней появилась претензия к УК. Если отметить одну копию, сверщик в течение минуты свернёт и уже пришедшие копии. «↩️ Вернуть» отменяет это для всей истории. Не присланные копии — в `/skipped`.
- **Чат не зарастает.** Закрытые карточки удаляются из Telegram и Max: «Ложное» и «Снято» через 30 минут, «Решено» через 2 часа (Настройки → «Убрать из чатов…», или `/set alerts.cleanup_false_min 30`; 0 — не убирать). Telegram не даёт боту удалять сообщения старше 48 часов: такие карточки остаются свёрнутыми. После обновления Радар за несколько минут уберёт и уже накопившиеся закрытые карточки, которые площадка ещё позволяет удалить.
- **Выключение из веб-интерфейса.** Кнопка ⏻ в шапке: «Выключить» (с подтверждением) или «Перезапустить». Команде уходит служебное «⏹ Радар выключен…», а после следующего запуска — «Радар не работал N ч: его выключили из веб-интерфейса». Ctrl+C в консоли больше не печатает трассировку. Коды выхода: 0 — выключен (start_radar.bat не перезапускает), 75 — перезапуск, остальное — сбой (перезапуск через 5 с). Служба systemd теперь `Restart=on-failure` (обновите `/etc/systemd/system/radar.service` и выполните `sudo systemctl daemon-reload`), cron-сторож не поднимает Радар, выключенный из GUI. В Docker кнопка «Выключить» недоступна (контейнер останавливают `docker compose stop radar`), «Перезапустить» работает.

## Где что лежит

`config/entities.yaml` — УК, ЖК, адреса, соседи (правится в GUI) · `config/sources.yaml` — источники · `config/watchlist.yaml` — люди на контроле (создаётся из `watchlist.example.yaml` при первом запуске; обновление архива её не перезаписывает) · `config/entities.learned.yaml` — дома, отмеченные в боте «наш/не наш» (пользовательский файл) · `data/` — база, отчёты, бэкапы, лог · `tools/e2e.py` — сквозной самотест · `pytest` — юнит-тесты.
