# Подготовка к передаче · 2026.11.05-handover.1

- Исключены рабочий `.env`, байткод, временные файлы и тестовые базы. Старый резервный YAML справочника не включён; актуальные справочники сохранены. Демонстрационные документы перенесены в `examples/` под читаемыми именами.
- Добавлены `.gitignore` и `.dockerignore` для секретов, данных и локальных файлов.
- Взят предоставленный автором `.env.example`; уточнены серверные пояснения, добавлены SMTP_STARTTLS и PUBLIC_URL. Ретрансляция токена Telegram в Colab по умолчанию выключена в шаблоне.
- `monitor/app.py` и `monitor/settings.py` читают файл по `RADAR_ENV_FILE`, если он указан; прежний `.env` остаётся совместимым вариантом для локального запуска.
- Добавлен `tools/preflight.py`: локальная проверка перед стартом, включая сохранённые в SQLite настройки. Слабый пароль GUI и публичный GUI блокируют серверный старт.
- Переработана systemd-служба: loopback, отдельный пользователь, ограничение записи папками data/config, закрытые права новых файлов, внешние секреты, предварительная проверка.
- Docker: непривилегированный пользователь, секреты как файл только для чтения, loopback-порт, папки данных на хосте, контролируемый выбор образа Ollama. Убрано ненадёжное скачивание модели после фиксированной паузы; модель загружается явным шагом.
- Caddy публикует только машинные API и health; GUI доступен через SSH. Старый VPS-скрипт оставлен для прежней схемы и помечен в инструкции как неприменимый к основной установке.
- Добавлен backup.sh с согласованной остановкой и возобновлением systemd-службы. Watchdog не поднимает намеренно остановленную службу.
- Зафиксирован установленный набор производственных зависимостей. Добавлены зависимости SOCKS-прокси для HTTPX и Telegram.
- Добавлены шесть проверок нового механизма конфигурации и документы передачи; основной README содержит ссылку на актуальную инструкцию.

Аналитические правила, интерфейс оператора и исходные тесты не переписывались. Результаты и ограничения — в `docs/VERIFICATION.md`.
